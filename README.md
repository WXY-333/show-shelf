# Halo 展示架插件

“展示架”是一个面向 Halo 2 的个人收藏展示插件，用来展示博主看过的动漫、影视、书籍以及其他自定义内容。

插件启用后会提供公开访问的 `/movie` 页面，并在 Halo Console 的“内容”分组中增加“展示架”管理入口。

## 基本信息

- 插件名称：展示架
- 当前版本：1.3.7
- 插件标识：`showcase`
- Halo 要求：2.23.0 及以上
- 当前测试环境：Halo 2.26.0
- 前台地址：`https://你的域名/movie`
- 开源协议：MIT

## 主要功能

### 展示内容管理

- 新增、修改和删除展示内容。
- 支持发布或隐藏内容，未发布内容不会出现在公开页面。
- 支持作品标题、分类、封面、观看状态、个人评分和排序值。
- 支持填写作品简介和观看后的感受。
- 观看链接为选填项：填写后详情中显示“去观看”，留空则不显示按钮。
- 封面可以从 Halo 附件库选择并立即预览，也可以填写外部图片 URL。

### 分类管理

- 默认创建“动漫”分类。
- 可以新增书籍、影视、游戏或任意自定义分类。
- 支持修改分类名称、Emoji 图标、说明和排序。
- 分类可以在前台显示或隐藏。
- 存在关联内容的分类不能直接删除，避免误删数据关系。

### 前台页面

- `/movie` 页面允许匿名访客公开访问。
- 支持分类筛选和标题、简介、感受关键词搜索。
- 卡片封面保持固定比例，不会因详情文字长度改变尺寸。
- 点击卡片后打开详情弹窗；较长内容可以在右侧独立滚动阅读。
- 详情滚动条颜色跟随后台设置的主题色。
- 页面底部包含鱼群与水波动画，支持鼠标扰动和点击翻转方向。

### 独立导航栏

展示架使用插件自己的导航栏，不会复制当前 Halo 主题的导航结构，因此切换博客主题后页面布局仍然保持一致。

- 左侧显示 Halo 后台设置的站点 Logo 和站点名称。
- 未设置 Logo 时自动尝试使用 favicon，再没有则显示樱花占位图标。
- 右侧提供昼夜切换和“返回博客”按钮。
- “返回博客”按钮使用后台设置的整体主题色作为底色。

### 主题颜色与昼夜模式

在“展示架 → 页面设置”中可以使用颜色选择器、色相滑块或十六进制颜色码设置整体主题色。

主题色会应用到：

- 页面背景与标题点缀
- 分类按钮与评分标记
- 返回博客按钮
- 卡片、详情弹窗与滚动条
- 鱼群、水波和页面装饰

导航栏的昼夜按钮可以切换日间和夜间配色。选择结果保存在访客浏览器中，再次访问时会继续沿用。

### 可选页面动效

后台页面设置支持开启或关闭全页面背景动效，并可选择：

- 樱花飘落：花瓣从页面上方缓慢飘落。
- 繁星点点：不同大小的星光在背景中交替闪烁。

标题区域还保留独立的樱花装饰。系统开启“减少动态效果”时，页面会自动停止装饰动画。

### Halo 评论区

展示架不会修改 Halo 的全局评论设置。评论区使用 Halo 官方“评论组件”的原生编辑器，访客登录、匿名评论、昵称、邮箱、网站和头像规则均由 Halo 评论组件及系统设置控制；展示架仅在自身页面设置开启时显示评论区。

后台页面设置支持开启或关闭 `/movie` 底部的公共评论区。评论区连接 Halo 官方“评论组件”插件，评论数据由 Halo 统一保存、审核和管理。

- 整个展示架页面共用一个稳定的评论主题。
- 切换博客主题或升级展示架插件不会改变评论主题标识。
- 评论区颜色会跟随展示架的主题色与昼夜模式。
- 如果评论组件未安装或未启用，前台会显示友好提示，不影响其他展示内容。

## 安装方法

1. 构建或取得 `plugin-showcase-1.3.7.jar`。
2. 进入 Halo Console 的“插件”页面。
3. 点击“安装插件”并上传 JAR 文件。
4. 安装完成后启动“展示架”插件。
5. 打开 Console 左侧“内容 → 展示架”。
6. 添加展示内容并设置为发布状态。
7. 访问 `/movie` 查看公开页面。

升级插件前建议保留 Halo 数据目录备份。正常升级不会删除已经创建的展示内容、分类或页面设置。

## 后台使用说明

### 添加展示内容

1. 打开“展示架 → 展示内容”。
2. 点击“添加展示内容”。
3. 填写标题并选择分类。
4. 点击“从 Halo 附件库选择”设置封面。
5. 按需填写简介、观看感受、状态、评分和观看链接。
6. 勾选“发布到前台 `/movie`”。
7. 保存后刷新公开页面即可看到卡片。

### 修改页面外观

1. 打开“展示架 → 页面设置”。
2. 修改页面标题、副标题和统计区文字。
3. 选择整体主题颜色。
4. 设置页面背景动效的开关和类型。
5. 按需开启或关闭页面评论区。
6. 保存后刷新 `/movie`。

开启评论区前，请先在 Halo 中安装并启用官方“评论组件”插件；如需匿名评论，请在 Halo 全局评论设置中主动开启，评论审核仍由 Halo 评论设置控制。展示架不会自动修改或恢复这些全局设置。

## 权限说明

插件提供以下角色模板：

- 展示架查看：允许进入插件后台并读取展示内容。
- 展示架管理：允许新增、修改、删除内容与分类，以及保存页面设置。
- 匿名访问：只允许读取已发布的公开内容、可见分类和公开页面设置。

非超级管理员需要被授予“展示架查看”和“展示架管理”权限。从附件库选择封面时，还需要相应的 Halo 附件读取权限。

## 项目结构

```text
src/main/java/
├─ ShowcasePlugin.java                 插件生命周期与默认数据
├─ ShowcaseEndpoint.java               前后台 API
├─ ShowcasePageRouter.java             /movie 页面路由
└─ extension/                           内容、分类和设置数据模型

src/main/resources/
├─ console/                             Halo Console 管理页面
├─ static/                              /movie 的 HTML、CSS、JS 和动画资源
├─ extensions/                          权限角色与静态资源代理规则
├─ plugin.yaml                          插件清单
└─ logo.svg                             插件图标
```

## 数据与接口

展示内容、分类和页面设置均通过 Halo Extension API 持久化，切换主题、重启 Halo 或升级插件不会主动清空数据。

公开接口：

```text
GET /apis/api.showcase.halo.run/v1alpha1/items
GET /apis/api.showcase.halo.run/v1alpha1/categories
GET /apis/api.showcase.halo.run/v1alpha1/settings
```

管理接口由 Halo 权限系统保护，不建议绕过 Console 直接调用。

## 注意事项

- 外部观看链接仅允许使用 `http` 或 `https`。
- 外部封面地址需要允许浏览器公开访问。
- 站点名称和 Logo 来自 Halo 系统设置，修改后刷新 `/movie` 即可同步。
- 昼夜模式属于访客浏览器偏好，不会修改后台保存的整体主题色。
- 页面背景动效开关与类型属于插件全局设置，对所有访客生效。
- 页面评论区依赖 Halo 官方“评论组件”插件；匿名评论开关、审核与通知规则请在 Halo 评论系统中管理，展示架不会修改全局评论配置。

## Steam 信息展示联动（0.3.0）

在“展示架 → 页面设置”中可以开启“Steam 游戏联动”。开启后，公开的 `/movie` 页面会自动增加“游戏”分类，通过“Steam 信息展示”插件的公开 API 读取游戏封面、累计游玩时长和最后游玩日期。游戏数据不会复制到展示架自己的内容库。

Steam 插件未安装、未启用或运行异常时，后台会显示依赖状态和处理提示，前台游戏分类也会显示明确提示。Steam 插件完成配置后，点击游戏卡片会在新标签页打开对应的 Steam 商店页面，分类顶部提供进入 Steam 完整资料页的入口。

## 1.3.7 发布信息

- 新增可选访客统计：今日访客、今日访问、总访客和总访问。
- 统计数据由展示架独立保存，使用展示架 Cookie 区分访客，不修改 Halo 全局配置。
- 页面设置中可单独开启或关闭访客统计。
- 修复访客统计关闭后匿名接口仍可能写入数据的问题：服务端会先检查开关，关闭时不会创建或更新统计数据。
- 限制访客 Cookie 输入为合法 UUID，超长或非法标识会被替换；持久化前使用 SHA-256 哈希，不保存客户端提交的原始标识。
- 采用有界去重存储：总访客标识最多保留最近 10,000 条，当日访客标识最多保留最近 5,000 条，超过容量时淘汰最早的标识，防止存储无限增长。
- 标识缓存容量与页面统计数字不是同一个上限。四项统计数字最高为 2,147,483,647，达到上限后停止增长，不会发生整数溢出。
- 同一访客 30 秒内只计数一次，并限制全局每分钟最多处理 600 次统计写入；并发请求会串行更新插件自己的统计 ConfigMap，避免计数覆盖。
- 去重缓存达到容量后，被淘汰的旧访客再次访问时可能被识别为新访客，这是控制存储容量所采用的统计精度取舍。
- 评论区仍由 Halo 评论组件保存和管理；展示架不会自动开启、关闭或恢复 Halo 全局评论设置。

- 电脑端 Steam 游戏分类固定为三列卡片布局。
- 手机端 Steam 游戏分类固定为两列卡片布局。
- 手机端短分类名称使用四列布局；较长分类名称按内容自适应排列，Steam 游戏分类会顺位显示在已有分类之后。
- 修复评论组件首次加载较慢时原生评论编辑器与展示架评论表单同时出现的问题。
- 移除展示架自定义评论表单，改用 Halo 原生评论编辑器，并调整原生编辑器提示文字。
- 放大手机端分类按钮的文字与图标，提升移动端可读性。
- 手机端普通大分类和二级分类统一使用两列卡片布局，不再根据作品数量切换单列。
- 修复黑夜模式下评论组件内部背景层叠加的问题，评论区保持统一卡片背景。
- 展示卡片最多显示前四个标签，手机端每行最多显示两个标签。
- 修复手机端标签隐藏规则被基础样式覆盖的问题，并缩小手机端评分和点赞控件。
- 评分徽章和点赞按钮改为保持原比例整体缩放，避免手机端控件变形。
- 手机端展示卡片最多显示前两个标签，并保持在同一行；桌面端显示规则不变。
- 修复手机端第二个标签因弹性宽度不足而被卡片边界截断的问题。
- 修复手机端标签被压缩成单字的问题，标签改为按内容宽度横向排列。
- 修复手机端标签容器宽度不稳定导致标签再次显示省略号的问题。
- 手机端标签背景框改为按标签文字内容自适应宽度，英文标签不再出现背景框与文字不匹配。
- 彻底取消手机端标签的固定宽度和省略号限制，确保前两个标签文字完整显示。
- 修复手机端导航栏站点标题被截断的问题，完整显示站点名称。
- 切换动漫、书籍和游戏分类时会自动清理旧的分组布局状态，不需要刷新页面。
- `/movie` 页面和已发布内容对访客公开，访客无需登录即可查看详情并切换白天/黑夜模式。
